# Var Mısın Yok Musun Oyunu

Bu proje, popüler TV yarışma programı "Var Mısın Yok Musun"un web tabanlı bir versiyonudur. Oyuncular 20 kutu arasından birini seçer ve diğer kutuları açarak ilerler. Banka belirli aralıklarla teklifte bulunur.

## Özellikler

- 20 farklı kutu ve ödül
- Dinamik banka teklifleri
- Animasyonlu telefon görüşmeleri
- Responsive tasarım (mobil uyumlu)
- Gerçekçi kutu açma animasyonları
- Anlık para tablosu güncellemesi

## Kullanılan Teknolojiler

- HTML5
- CSS3
- JavaScript (ES6+)
- jQuery 3.5.0
- Bootstrap
- Font Awesome 6.5.1

## Nasıl Oynanır

1. "Şimdi Oyna" butonuna tıklayarak oyunu başlatın
2. 20 kutudan birini seçin - bu sizin kutunuz olacak
3. Diğer kutuları sırayla açın
4. Her banka teklifinde:
   - "VARIM" derseniz teklifi kabul edersiniz
   - "YOKUM" derseniz oyuna devam edersiniz
5. Son kutuya kadar giderseniz, kendi kutunuzdaki miktarı kazanırsınız
